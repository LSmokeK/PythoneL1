# Лабораторна робота №2 — сайт-резюме

Персональний навчальний Flask-сайт Євгенія Вербицького.

## Локальний запуск

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Відкрийте http://127.0.0.1:5000/.

## Render

- Root Directory: `Lab2`
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`

Форма контактів демонстраційна: не надсилає листи. Фото залишене з оригінального архіву.
